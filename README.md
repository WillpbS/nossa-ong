# Nossa ONG

Projeto front-end desenvolvido para conectar voluntários e doadores a causas sociais.

## Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Variáveis CSS e Modo Escuro)
- JavaScript (ES Modules)
- Vite (Bundler para produção)

## Como executar o projeto
1. Instale as dependências: `npm install`
2. Gere a versão de produção: `npm run build`
